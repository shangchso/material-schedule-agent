# 04 AI 辅助使用记录

按照笔试要求，如实记录 AI 辅助工具的使用范围、个人修改与验证结果。

## 1. AI 辅助范围

- 协助理解笔试题目与交付规范，梳理目录结构与验收点清单。
- 辅助生成项目代码初稿（数据存储层、四个工具、MockLLM 决策逻辑、Agent 主循环、CLI 入口）。
- 辅助生成文档初稿（本目录五份文档与 README）。
- 辅助设计合成数据与测试用例。

## 2. 个人负责的判断与修改

- 确定技术选型：Python 原生实现，不引入 Agent 框架，理由记录于 02-solution.md。
- 确认业务边界：系统只存草稿、不发布；替代时段必须经用户确认；保存失败如实返回。
- 在运行验证中发现并修复一处决策缺陷：用户确认替代时段并保存成功后，决策模型未识别"已保存"状态，重复触发保存动作直到步数上限；通过在决策分支中增加保存状态判断修复，修复后重新运行确认路径正常结束（6 步 approved）。
- 逐条核对 6 个验收点与官方要求的对应关系。

## 3. 个人验证结果

- 单元测试：9 个用例全部通过。
- 端到端：6 个场景 CLI 实跑结果与预期一致，Trace 已落盘 examples/traces/。
- 红线自查：无"已发布"状态、无越权修改硬性要求、无虚报保存成功。
